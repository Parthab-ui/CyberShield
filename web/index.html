About CyberShield

Course Project

Project Overview

CyberShield is an integrated Cybersecurity Monitoring and Incident Management System designed for educational demonstration and enterprise SOC workflow simulation. It provides centralized threat logging, role-based incident triage, unauthorized access tracking, and real-time posture reporting.

System Architecture

The system adheres to a decoupled client-server architecture sharing a single SQLite database:

  • Web Frontend: Pure HTML5, CSS3, and vanilla JavaScript communicating with the backend via REST API.
  • Backend Server: Lightweight embedded Java HTTP server (com.sun.net.httpserver) providing JSON endpoints and session management.
  • Database Layer: Persistent SQLite storage accessed via plain JDBC and secure prepared statements.
  • Desktop Client: Full-featured Java Swing desktop application on Event Dispatch Thread (EDT) connected to the same backend.
